    Apple Health setup (one time)
    1. Open the Shortcuts app → + → name it exactly as the Shortcut name above (default “Log Water”).
    2. Add action Get Text from Input (set the shortcut to accept Text input).
    3. Add action Log Health Sample → Type: Water, Value: the text from step 2, Unit: fl oz (or mL to match your setting).
    4. Back here, turn on Sync to Apple Health. Each time you log water, the Shortcuts app flashes open, writes the sample, and you swipe back.
    5. Add this page to your Home Screen (Share → Add to Home Screen) for the full-screen app.
    Sync is one-way: this app writes to Health, it can't read other water entries.
